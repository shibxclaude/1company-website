# 视觉规范：现代科技风（2026-11 改版）

> 应需求方要求，官网从"还原原站"改为现代科技风格。这意味着 Task1 验收标准第 1 条"视觉与原站基本一致"不再作为目标；内容、栏目、路由、ICP 备案展示和全部功能都保持不变。
> 截图：`docs/design/screenshots/`

## 设计思路

题材是公安、政务的数据融合与物联网，原站的核心叙事是"区域一张网"。所以全站只在一个地方用力：首页首屏右侧的**区域等高线地图**。它带经纬刻度，页面加载时一条轨迹线依次串起"卡口 → 社区 → 派出所 → 物联感知 → 政务数据 → 指挥中心"，这是全站唯一一段非交互动画；系统开启"减少动态效果"时直接显示终态。其余部分都保持克制：左对齐的标题，用细线分隔信息，不堆叠相同样式的卡片，也不给每个区块加入场动画。

刻意避开的通用"科技风"做法：近黑底配霓虹强调色、发光卡片网格、大数字统计条、全大写英文小标题、标题里单独给某个词换颜色、链接末尾加箭头。

## 色板（`frontend/www/src/styles/tokens.css`）

| 名称 | 色值 | 用途 |
|---|---|---|
| 墨蓝 `--c-ink` | `#0B1F3A` | 首屏、内页页头、页脚、导航（滚动后或无页头的页面）、标题文字 |
| 地图纸 `--c-paper` | `#F3F6FA` | 内容区交替底色 |
| 政务蓝 `--c-brand` | `#1D5BFF` | 按钮、链接、选中态 |
| 信号琥珀 `--c-signal` | `#FFAA2C` | 只用于地图上的数据点、轨迹，以及导航当前项的下划线 |
| 价格橙 `--c-price` | `#E8590C` | 价格和金额（延续国内用户对价格颜色的习惯） |
| 细线 `--c-line` | `#DCE3EE` | 分隔线、边框 |

## 字体

- 中文：系统黑体（苹方 / 鸿蒙黑体 / 微软雅黑），不加载网络字体。
- 数字、价格、订单号、坐标刻度：**Barlow Semi Condensed**（一款类似 DIN 的工业仪表风格字体，OFL 授权），通过 `@fontsource` 打包进项目、自托管，只含拉丁字符子集，不依赖 Google Fonts。
- 字号阶梯按 1.25 倍递进：12 / 14 / 16 / 20 / 25 / 31 / 39px；首屏标题 32–56px 自适应。

## 布局

- 内容最大宽度 1200px，左右各 24px 边距，首屏、导航、各区块的左边缘对齐。
- 区块标题左对齐，"标题 + 一句说明"，右侧可以放一个链接（如"查看完整价格公示"）。
- 首页解决方案采用**目录式列表**：每行依次是缩略图、分类、名称、简介、价格、"了解详情 / 立即购买"，价格对访客一目了然。
- 内页页头改为墨蓝底配淡等高线纹理，包含面包屑、h1 和副标题。原站的 banner 图片自带"当前位置"等文字，改版后不再使用。
- 圆角：按钮和输入框 4px，面板 8px。不使用胶囊形按钮。

## 遗留问题

- 解决方案详情里的"方案图解"是原站的整张长图，里面的标题仍是旧风格（蓝色居中加横线）。这属于后台富文本内容，可以在管理后台删除或替换成新图，不需要改代码。
- 合作伙伴仍是原站的整图，在手机上字很小。如果需要，可以改为后台维护的文字列表。

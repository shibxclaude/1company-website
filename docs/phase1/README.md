## 0. 结论先行（需要你拍板的事项见第 6 节）

1. **原站没有可售卖的产品数据。** "产品中心"两个页面各只有一张整图，分别是"信息技术应用能力"和"产品生态树"，里面没有名称、价格、介绍这样的结构化产品。
   最接近"产品"的是 **6 个解决方案**，每个都有独立详情页，所以建议把它们作为首批 6 个上架产品。**价格、版本、计费方式、交付方式原站完全没有，需要业务方提供。**
2. **除首页和常见问题外，所有内页的正文都是一整张 1920px 宽的图片。** 这样搜索引擎读不到文字，手机上字也小到看不清。6 个产品页和关于我们页的文字我已经从图里转录出来（见 `products-seed.json` 和第 3 节），迁移时可以改成真正的 HTML 文字。
3. **原站移动端是坏的。** 首页各区块写死了 `height: 600px / 400px / 500px`，在手机上内容溢出、相互重叠，页脚直接盖在解决方案图片上（见 `screenshots/index-m.jpg`）。验收标准第 6 条要求"移动端响应式可用"，所以**移动端不能 1:1 照搬，需要重做布局**；PC 端按原样还原。
4. 所有页面的 `<title>` 都是"北京一零科技有限公司"，且都没有 `description`，SEO 基本是空白。
5. 原站资源**没有 404**（已用浏览器逐页加载验证）。另外发现 25 张从未被引用的图片、2 个缺失的字体文件，以及一段加载不存在的 `footer.html` 的死代码。

# 任务：官网由静态 HTML 迁移至 Vue3，并实现产品中心后台配置与在线售卖

## 一、背景与目标

我们是一家软件公司，官网目前是纯静态 HTML 页面。本次要做两件事：

1. **整站迁移**：将现有官网从静态 HTML 迁移到 Vue3 工程化项目，视觉与内容参照现有网站，
   保持外观基本一致；
2. **产品中心升级 + 在线售卖**：迁移过程中重点改造产品中心——产品信息从后台可配置并
   动态展示，支持产品定价、在线下单、在线支付。

背景：我们正在申请《信息服务业务（仅限互联网信息服务）》经营许可证（ICP经营许可），
监管审核要求网站必须体现"通过互联网向上网用户有偿提供产品及信息服务"的经营性特征，
因此产品价格须对访客公开可见，购买支付流程须完整可演示。

## 二、第一阶段：现状梳理（先做，产出报告经我确认后再动代码）

1. 盘点现有静态官网的页面清单（首页、产品中心、关于我们、新闻等），每页截图归档
2. 提取现有站点的视觉规范：主色、字体、页头页脚结构、通用样式，整理为迁移基准
3. 梳理产品中心现有内容：现有产品数量、每个产品的信息结构（名称、图片、介绍等），
   整理为产品初始数据（后续导入数据库）
4. 梳理现有 URL 结构，制定新旧路由映射表，确保迁移后旧 URL 不 404

## 三、第二阶段：Vue3 工程搭建 + 官网页面迁移

- 技术选型：Vue3 + Vite + Vue Router（history 模式），官网前台不引重型组件库，
  按需引入即可；状态管理 Pinia
- 搭建多页应用结构：官网前台（www 站点）与后台管理（admin）分模块组织
- 逐页迁移：首页、关于我们、新闻动态等页面按现有视觉 1:1 还原为 Vue 组件，
  页头页脚做成公共组件
- **SEO 保障**：每个页面独立的 title / description（用 vueuse/head 或 unhead）；
  首页与产品页做预渲染（vite-ssg 或 prerender，二选一，说明理由）；生成 sitemap.xml
- **URL 兼容**：按第一阶段的映射表配置路由；静态资源旧路径做重定向；
  给出 nginx 部署配置（SPA history 模式 try_files、gzip、缓存策略）

## 四、第三阶段：产品中心后台化（本次核心）

### 1. 后端与管理后台

- 后端：Spring Boot + MyBatis-Plus + MySQL + Redis（现有技术栈，如有则复用）
- 产品数据表设计（参考）：

  product_category（产品分类表）：id、分类名、排序、状态
  product（产品表）：id、分类id、名称、主图、图集JSON、一句话简介、富文本详细介绍、
    服务说明（交付方式：在线开通/下载授权/远程部署、售后支持、服务期限）、
    状态（上架/下架）、排序、创建/更新时间
  product_version（产品版本表）：id、产品id、版本名、价格、原价、计费方式
    （一次性买断/按年订阅）、版本差异说明、状态

- 管理后台（Vue3 + Element Plus，独立登录）：
  - 产品管理：增删改查、上下架、排序、多图上传（复用现有文件服务或新建上传接口）
  - 产品版本与定价管理：每产品多版本、价格、计费方式
  - 产品分类管理
  - 将第一阶段整理的产品初始数据导入

### 2. 官网前台产品中心

- 产品列表页：从接口动态获取，分类筛选、搜索、价格醒目展示、"立即购买"按钮
- 产品详情页：图集轮播、富文本详情、版本选择（价格联动）、购买数量、金额汇总、
  交付方式与服务说明、"立即购买"
- 首页导航保留"产品中心"入口 + 首页产品推荐位
- 产品页做好缓存（Redis + 前端缓存），后台改价前台即时生效，无需发版

## 五、第四阶段：在线交易链路（ICP 审核关键）

- **价格公示页（/price）**&#8203;：表格汇总全部在售产品、各版本价格、计费方式、增值服务价目
  （额外部署/培训/延长维护等），**无需登录即可访问**——监管核查重点
- **下单页**：已选产品/版本/数量及金额汇总 + 表单（姓名、手机号、邮箱、企业名称选填、
  备注），游客可直接提交，生成订单号跳转支付（不强制先注册）
- **支付页**：微信支付 Native 扫码支付（官方 SDK），30分钟未支付自动关单，
  支付倒计时、支付成功页 + 邮件/短信通知；开发阶段支持沙箱/模拟模式（配置开关切换）
- **用户中心（/user）**&#8203;：注册/登录（手机号+验证码 或 账号密码，密码 BCrypt）、
  我的订单（待支付/已支付/服务进行中/已完成/已取消）、订单详情、电子协议查看
- **协议页（/agreement）**&#8203;：《产品购买服务协议》（交付方式、权利义务、付款、退款条款、
  知识产权、违约责任）、《隐私政策》
- **页脚**：所有页面展示 ICP 备案号并链接工信部 beian.miit.gov.cn
- 后台订单管理：订单列表、状态筛选、详情、手动标记服务进度；用户管理

## 六、技术要求与约束

- 所有金额字段 DECIMAL 存储，禁止 float/double；订单号 = 日期 + 业务码 + 随机数
- 支付回调必须签名验证 + 幂等处理（防重复入账）
- 接口入参统一校验（@Validated），异常统一返回 {code, msg, data}
- 官网前台与后台管理代码分目录/分路由隔离，后台接口全部鉴权
- 分阶段交付，每阶段给出：路由清单、接口清单、表结构变更清单、nginx 配置变更
- 部署方式：nginx 托管 Vue 构建产物 + 反代后端接口，给出完整部署脚本与回滚方案

## 七、验收标准

1. 迁移后官网各页面视觉与原站基本一致，旧 URL 全部可访问（或正确重定向）
2. 后台新增/修改产品（含图片、详情、版本、价格），前台无需发版即可见
3. 未登录访客可直接看到产品价格、购买入口、价格公示页全部内容
4. 从浏览产品 → 选版本 → 下单 → 出现支付二维码全程无报错、可完整演示
5. 支付成功后订单状态正确流转，后台可见并可处理
6. 全站移动端响应式可用
7. 页脚 ICP 备案号展示并外链工信部
8. 首页、产品页 title/description 正确，预渲染生效（查看源码可见内容）
